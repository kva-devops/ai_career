# Career Navigator · Java

Локальное приложение по ТЗ AI-карьерного консультанта для Java-разработчиков.

## Запуск

1. Установите зависимости и поднимите базу:

```powershell
npm install
docker compose up -d
```

2. Создайте `admin.txt` в формате:

```text
login: admin@example.com
password: change-me-please
```

3. Запустите сервер:

```powershell
npm start
```

Приложение будет доступно на `http://127.0.0.1:8000`. При старте сервер выполняет миграции и создаёт/обновляет администратора из `admin.txt`. Файл содержит секреты и добавлен в `.gitignore`.

Ключ из `env.txt` не подключается к браузерному коду: для ProxyAPI его следует использовать только сервером.

## Реализовано

- адаптивный интерфейс в визуальном направлении `refer1.jpg`;
- анкета с пропусками и значением «Пока не знаю»;
- диалог с состояниями пустого результата и быстрыми ответами;
- симуляция цепочки аналитик → генератор → критик → улучшатель;
- три карточки карьерных треков, выбор и пересмотр;
- память с редактированием, забыванием факта и полной очисткой;
- сохранение состояния после перезапуска браузера;
- PostgreSQL в Docker с постоянным volume;
- PBKDF2-хеширование паролей и HttpOnly-сессии;
- регистрация клиентов и отдельная роль `admin`;
- базовая admin-панель со списком пользователей;
- серверные API профиля, диалогов, сообщений и планов.
- загрузка PDF-резюме из панели «Ваш профиль» с ограничением 10 МБ;
- извлечение текстового слоя PDF, заполнение подтверждённых полей профиля и сохранение версии резюме;
- модельное извлечение проектов и технологий через ProxyAPI с локальным fallback при недоступности API.

PDF без текстового слоя (скан без OCR) отклоняется с понятным сообщением — это защищает профиль от заполнения случайным или непроверяемым текстом.
